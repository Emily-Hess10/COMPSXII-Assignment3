Structs vs Classes
In this assignment, I used a C struct to create something similar to a class in Python. In Python, a class can contain data and methods together, and Python automatically handles a lot of the work. In C, I had to do those steps myself. I created the Character struct with the character's name, health, and level. I also added function pointers for attack and take_damage. I then created separate functions for those behaviors and connected the function pointers to them in the character_init function. I also had to pass a Character pointer to the functions as the "self" parameter. In Python, when I call hero.attack(), Python automatically knows which object is calling the method. In my C program, I had to use the function pointer and pass the character pointer myself.
Inheritance Implementation
C does not have classes or built-in inheritance like Python does, so I used composition to create the Warrior and Mage types. Both the Warrior and Mage structs contain a Character struct as their first member. The Warrior also has a strength value, while the Mage has a mana value. Because the Character struct is the first member, I could treat a Warrior or Mage as a Character when using the function pointers. Python makes inheritance much simpler because I can write something like class Warrior(Character) and automatically inherit the parent class's data and methods. The C approach requires more code and more steps, while Python's syntax makes inheritance easier to read and use.
Understanding OOP Mechanics
Function pointers allow polymorphism because different character types can have different functions assigned to the same attack function pointer. The basic Character uses character_attack, while the Warrior uses warrior_attack and the Mage uses mage_attack. This means I could create an array of Character pointers and call attack on each character using the same type of function call. The result was different depending on which character was in the array. This helped me understand how polymorphism can work underneath the simpler Python class system.
Systems programmers may use this type of design because C is used in areas where programmers need more direct control over memory and performance. C does not provide classes automatically, but structs and function pointers can still be used to organize data and behavior. This assignment helped me understand that features like classes, inheritance, and polymorphism can be built using lower-level programming concepts. It also showed me that Python handles many of these details automatically, while C requires the programmer to set them up manually.
